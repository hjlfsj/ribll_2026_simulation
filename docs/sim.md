同时利用python丰富的库，如numpy、matplotlib等，实现数据的可视化和分析。

配置文件详细：

- 反应类型：
    - 1：A* $\to$ B + C, 即处于激发态的A粒子衰变成B和C两个粒子。A粒子具有初始动能和激发能，B和C均为基态。激发能加在母核A上，且必须大于基态Q值的绝对值（-Q_gs），否则衰变在能量上不可行。
    - 2：A + B $\to$ C + D, 即A粒子以一定的动量和静止的B粒子发生碰撞，碰撞后生成C和D两个粒子。A粒子和B粒子的动量和能量必须满足守恒定律。A,B都默认为基态。当C=A, D=B时，为弹散或者非弹散碰撞。当不满足时，为转移反应，C和D粒子只有D能设置为激发态。C默认基态
    - 3： 第三种情况为在第二种情况的基础上, 处于激发态的C发生破裂，生成E和F两个粒子。E和F粒子的动量和能量必须满足守恒定律。E粒子默认为基态，F粒子可以设置激发态。

    关于以上反应类型的计算，可以参考reference中pyroot中各个文件的算法。所有计算都以相对论四动量的方式进行，
    使用ROOT库中的TVector4类。
    这些模块实现后，同时需要在test_module/目录下实现对应的测试模块，用于测试这些模块的正确性。

- 探测器配置：
target几何中心设置在(0,0,0)处，为一个直径30mm，厚度可设置的圆柱。厚度的单位为um，默认为100um。
圆柱的对称轴为z轴，即(0,0,0)处的点为圆柱的中心。
target可以设置为

探测器的类型分为 DSSD,SSD,和 CsI三种。前两种为Si探测器，第三种为CsI探测器。
其中si探测器的尺寸均为64mm*64mm,厚度自行设定，对称轴为z轴。
DSSD可以设置为64*64格，每个格的尺寸为1mm*1mm。或者设置为32*32格，每个格的尺寸为2mm*2mm。

目前我们设置五块硅探测器：
    1. DSSD*32, z=100mm，厚度为68um。
    2. DSSD*64, z=110mm，厚度为1000um。
    3. DSSD*32, z=120mm，厚度为1000um。
    4. DSSD*32, z=130mm，厚度为1000um。
    5. SSD, z=140mm，厚度为1500um。

- 模拟探测过程：

首先，我们默认上述反应都在target内以极端的时间发生。反应点在靶的内部均匀分布。
然后，我们根据反应类型，计算出每个粒子的动量和能量。然后根据粒子位置判断粒子是否能够离开靶。如果能够离开靶，我们记录下粒子的位置和动量。然后计算靶中能损。并得到粒子离开靶后的能量，然后判断粒子的几何轨迹是否能够进入下一个探测器，以及进入后能否穿透该探测器。
最终，如果一个反应的所有粒子都成功阻停在Si探测器（不包含DSSD1）中，我们记录下该反应的事件。并绘制各个粒子的E_theta曲线，并重建该反应激发能谱。
对于三种反应类型：1.重建A的激发能，2.重建D的激发能，3.重建F的激发能。
该过程中的能损相关计算参照reference中brill2中的catima,可以同样的生成临时文件在asset中
